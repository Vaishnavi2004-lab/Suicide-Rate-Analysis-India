# 📊 Suicide Rate Analysis - India

## 🚀 Project Overview
This project is an interactive analytics dashboard developed using Python and Streamlit to analyze suicide trends across India.

The dashboard provides:
- State-wise analysis
- Year-wise analysis
- Gender-based analysis
- AI-generated insights
- Interactive visualizations
- Downloadable filtered reports

---

## 🔥 Features

✅ Interactive Dashboard  
✅ Dynamic State Filter  
✅ KPI Cards  
✅ Plotly Visualizations  
✅ Gender Analysis  
✅ AI Insights  
✅ CSV Download Feature  
✅ Multi-page Navigation  
✅ Professional Dark UI

## 📈 Dashboard Analysis

### 1. State-wise Analysis

### 2. Year-wise Trends
