# Suicide Rate Analysis India

Interactive Suicide Rate Analysis Dashboard using Python and Streamlit.

## 📌 Project Overview
This project analyzes suicide rates in India using data visualization and Python libraries.

## 🚀 Features
- Data Cleaning and Analysis
- Interactive Charts
- Streamlit Dashboard
- Year-wise Analysis
- State-wise Insights

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

## 📂 Dataset
Suicides in India 2001-2012 Dataset

## ▶️ Run Project

```bash
pip install -r requirements.txt
streamlit run app.py
